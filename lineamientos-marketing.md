## Lineamientos de Marketing para Newsletters

- Las noticias tienen que ser relevantes para un contexto empresarial como Bancos, Aseguradoras, Telecomunicaciones, Retail, entre otras similares.
- El público objetivo son desarrolladores de software y profesionales de la tecnología en empresas del sector mencionado.
- Prefiere las siguientes tecnologías o herramientas relacionadas con nuestro negocio.
    - GitHub y GitHub Copilot
    - Microsoft Azure
    - Microsoft Foundry
    - OpenAI

### Ejemplos

**NO Relevante:**
- Building games with Astra: How I built a procedural space exploration game in Codex, from concept art to planets you can land on.

No es relevante porque el sector empresarial objetivo no está interesado en el desarrollo de juegos.

**Relevante:**
- GitHub Copilot app for Beginners: Run several agents at once: Learn how to run parallel agents in the GitHub Copilot app, and experience the moment it stops feeling scary and starts feeling powerful.

Es relevante porque los desarrolladores de software pueden beneficiarse de aprender a ejecutar agentes de GitHub Copilot.
