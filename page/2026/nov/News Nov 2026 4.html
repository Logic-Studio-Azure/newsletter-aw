Agent Host Protocol: sesiones de agentes que continúan entre dispositivos

GitHub presenta el Agent Host Protocol (AHP), un estándar abierto que permite iniciar una sesión de agente de Copilot en un editor y continuarla desde otra aplicación o dispositivo, sin perder contexto. Para empresas de banca, seguros y telecomunicaciones, esta capacidad facilita que equipos distribuidos trabajen con agentes de IA de forma continua y segura, integrándolos en sus propios flujos y herramientas corporativas.

Así es la nueva arquitectura de almacenamiento Git de GitHub

GitHub detalla su nueva arquitectura de almacenamiento Git, diseñada para soportar miles de agentes escribiendo simultáneamente en un mismo repositorio, con hasta 7,200 pushes por segundo y baja latencia de lectura. Esta evolución es clave para organizaciones empresariales con grandes equipos de desarrollo que adoptan agentes de IA a gran escala, asegurando que la infraestructura de código pueda escalar sin sacrificar rendimiento ni confiabilidad.

Cómo integrar la revisión de seguridad en tu SDLC con Codex Security

OpenAI comparte cuatro principios para construir flujos de revisión de seguridad agénticos con Codex Security y su CLI, que permiten detectar código inseguro al mismo ritmo en que los agentes de IA generan y modifican código. Esta propuesta es muy relevante para empresas de sectores regulados como banca y telecomunicaciones, donde escalar la seguridad del ciclo de vida de desarrollo de software es una prioridad crítica.

Anthropic dona Agent Skills a la Agentic AI Foundation

Anthropic dona el estándar abierto Agent Skills, ya adoptado por más de 70 plataformas de agentes incluyendo ChatGPT, GitHub Copilot y VS Code, a la Agentic AI Foundation bajo la Linux Foundation. Las "skills" permiten que los agentes de IA incorporen conocimiento específico de negocio y procedimientos propios de cada organización, algo valioso para empresas de banca, seguros y retail que buscan estandarizar el uso de agentes en sus equipos de desarrollo de forma abierta y neutral frente a proveedores.
