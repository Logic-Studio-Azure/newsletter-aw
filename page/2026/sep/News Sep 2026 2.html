Migrando el runtime de GitHub Copilot a Rust, usando Copilot

GitHub reescribió por completo el runtime del agente de Copilot, pasando de TypeScript/Node.js a más de 800,000 líneas de Rust en producción. Usando el propio GitHub Copilot app y Copilot CLI, los agentes de IA escribieron la mayor parte del código en 128 pull requests, mejorando el rendimiento en órdenes de magnitud. Este runtime es la base de Copilot CLI, la app de Copilot, VS Code, Visual Studio, Copilot Code Review, Copilot Cowork y más, mostrando cómo la IA agente permite modernizaciones a gran escala que antes requerían equipos completos durante años.

Project HydraFusion: calidad de frontera mediante orquestación multi-modelo

GitHub presenta Project HydraFusion, una vista previa de investigación que ofrece inteligencia de frontera mediante orquestación en tiempo de ejecución. HydraFusion crea un plan de ejecución completo, seleccionando entre modelos de múltiples proveedores para redactar, criticar y revisar, o escalar a modelos más potentes según la tarea. En evaluaciones controladas, sus flujos de codificación selectiva igualaron o superaron al modelo base Opus 5 evaluado, reduciendo el costo estimado, todo de forma transparente para el desarrollador.

Cómo hacemos que la codificación con IA sea más eficiente en costo sin sacrificar calidad

GitHub explica por qué el conteo de tokens por interacción no es una medida útil de eficiencia: lo importante es completar la tarea con el contexto adecuado, evitando llamadas adicionales innecesarias. El artículo detalla cuatro cambios implementados en GitHub Copilot que optimizan el resultado final en lugar de cada llamada individual, reduciendo el trabajo desperdiciado a lo largo de toda la tarea de codificación y logrando ahorros de costo reales para equipos empresariales que usan Copilot a gran escala.

GitHub Copilot app para principiantes: ejecuta varios agentes a la vez

Ejecutar múltiples agentes de IA en el mismo proyecto puede parecer caótico, pero con la GitHub Copilot app cada agente trabaja de forma independiente sin interferir con los demás, permitiendo avanzar en más tareas al mismo tiempo. Es como llevar varias cargas de ropa a la lavandería: cada una en su propia máquina, con su propia configuración, sin necesidad de esperar a que termine una para iniciar otra. Esta guía práctica muestra cómo aprovechar sesiones de agentes en paralelo para equipos de desarrollo que buscan escalar su productividad.
