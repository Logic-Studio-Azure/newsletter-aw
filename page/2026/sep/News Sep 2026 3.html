Cuando el chat no es la interfaz correcta: los "canvases" de GitHub Copilot

GitHub explica por qué el chat es útil para expresar intenciones, pero se queda corto cuando el trabajo de un agente se pierde en el scroll de una conversación. Presenta los "canvases", espacios de trabajo interactivos donde los desarrolladores pueden visualizar información, explorar flujos de trabajo y tomar acciones concretas sobre tareas complejas de codificación con IA. El artículo detalla cómo estos lienzos complementan al chat en flujos de trabajo agénticos, ofreciendo a los equipos empresariales una forma más tangible y eficiente de supervisar el trabajo de los agentes de Copilot.

Fuzzing potenciado por IA con el GitHub Security Lab Taskflow Agent

GitHub Security Lab presenta un nuevo taskflow de fuzzing basado en su framework de IA Taskflow Agent, diseñado para automatizar la detección de vulnerabilidades en el código. El artículo explica paso a paso cómo configurar y ejecutar este flujo de trabajo agéntico para descubrir errores de seguridad de forma proactiva, una capacidad especialmente relevante para organizaciones en sectores regulados como banca y telecomunicaciones que necesitan fortalecer sus prácticas de seguridad de aplicaciones sin aumentar la carga manual de sus equipos.

Reglas personalizadas de revisión de código para Codex

OpenAI presenta reglas de revisión de código personalizadas para Codex, que permiten a los equipos definir lineamientos específicos —como preservar contratos de API o evitar exponer datos sensibles en logs— para que el agente los aplique automáticamente durante las revisiones. En pruebas controladas, las variantes guiadas por reglas recuperaron el 98% de los hallazgos requeridos, frente a solo 58.3% en el control base, mostrando cómo la IA puede escalar el conocimiento institucional de revisores experimentados a equipos completos de desarrollo empresarial.

Anthropic desarrolla Enterprise Frontier Safeguards junto a sus clientes

Anthropic anuncia Enterprise Frontier Safeguards (EFS), una solución que combina retención cero de datos con salvaguardas de última generación para detectar mal uso, almacenando los datos en infraestructura controlada por el propio cliente. Desarrollada junto a más de 100 empresas de sectores como servicios financieros, telecomunicaciones, retail y salud, EFS estará disponible en Claude Code, Claude Enterprise, Amazon Bedrock, Google Cloud y Microsoft Foundry, reforzando la confianza de las organizaciones que adoptan modelos de IA cada vez más agénticos.
