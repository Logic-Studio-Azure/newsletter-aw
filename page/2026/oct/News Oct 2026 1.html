Barclays escala Claude para modernizar operaciones y mejorar la experiencia de sus clientes

Barclays, el banco universal británico, amplía su colaboración estratégica con Anthropic para integrar sistemas de IA seguros y de nivel empresarial en sus operaciones globales. El banco está extendiendo Claude para acelerar el desarrollo de software, modernizar sistemas legados y mejorar la eficiencia operativa, con el objetivo de que la adopción de Claude Code alcance al 50% de su población de desarrolladores para finales de 2026, y a la mayoría de los ingenieros de software en 2027. Un caso concreto de cómo la banca está adoptando IA agente para modernizar su stack tecnológico.

El modelo de GitHub para detección de secretos: más hallazgos con menos ruido

GitHub presenta un nuevo clasificador de secretos sensible al contexto que mejora la calidad de detección en el escaneo de secretos, aumentando la tasa de aceptación ponderada en un 11.5% y reduciendo el tiempo medio de ejecución del escaneo en un 86% frente al pipeline anterior basado en LLM. Esta mejora permite extender la protección en el push, deteniendo credenciales antes de que se filtren, en lugar de solo después del commit. Una actualización clave para equipos empresariales que gestionan seguridad de código a gran escala en sectores regulados como banca y telecomunicaciones.

GitHub Copilot app para principiantes: cómo enseñarle a Copilot sobre tu base de código

Esta guía práctica explica cómo agregar instrucciones y skills personalizadas a tu repositorio, usar agentes personalizados y conectar servidores MCP como Playwright para que GitHub Copilot comprenda mejor el contexto de tu proyecto. Reglas personalizadas de revisión de código para Codex

OpenAI anuncia que Codex Code Review ahora puede usar reglas personalizadas del repositorio definidas en AGENTS.md para detectar problemas recurrentes, como exponer datos de clientes en logs o romper contratos de API, y señalar a los autores la guía detrás de cada hallazgo. Con el volumen de pull requests duplicándose desde el último trimestre, esta función ayuda a equipos empresariales a escalar la revisión de código sin perder contexto institucional, especialmente cuando colaboradores o agentes trabajan en partes poco familiares del repositorio.
