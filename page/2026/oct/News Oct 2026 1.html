Barclays escala Claude para modernizar operaciones y mejorar la experiencia del cliente

Barclays amplía su colaboración estratégica con Anthropic para integrar sistemas de IA seguros y de nivel empresarial en sus operaciones globales. El banco espera que la adopción de Claude Code llegue al 50% de su población de desarrolladores para finales de 2026, usándolo para acelerar el desarrollo de software y modernizar sistemas legados. Ya en producción, su asistente de conocimiento para colaboradores —impulsado por Claude mediante RAG— ha sido adoptado por más de 16,000 empleados y ha gestionado más de un millón de búsquedas, mientras otros equipos procesan unos 120,000 correos diarios con modelos Claude para clasificar y priorizar solicitudes de clientes.

Renderizando pull requests enormes en la GitHub Copilot app

El equipo de ingeniería de GitHub explica cómo reconstruyó la superficie de diffs en la GitHub Copilot app para poder abrir pull requests de hasta un millón de líneas, con cientos de comentarios de revisión en línea, sin degradar el rendimiento. Este trabajo de optimización es clave para equipos empresariales que manejan bases de código grandes y necesitan revisar cambios masivos generados por agentes de IA de forma fluida y confiable.

Reglas personalizadas de revisión de código para Codex

Codex Code Review ahora puede usar reglas personalizadas del repositorio definidas en AGENTS.md para detectar problemas recurrentes, como romper contratos de API antiguos o exponer datos sensibles en logs, y señalar a los autores la guía detrás de cada hallazgo. Con el volumen semanal de pull requests más que duplicado en OpenAI desde el Q4, esta función ayuda a los equipos empresariales a mantener estándares de calidad y seguridad incluso cuando contribuyen agentes o desarrolladores nuevos que desconocen el historial del proyecto.
